# Implementer brief

The coordinator supplies:

- The working directory, user outcome and acceptance criteria for this unit.
- The files or component the worker owns, the interfaces it shares, and dependencies already in place.
- The applicable repository instructions and focused checks, including any shared resource reserved for the integrated run.

The worker reads the relevant code and chooses the smallest change that satisfies the criteria. Preserve existing work. If a change needs another worker's files or the code contradicts a material assumption, report the conflict to the coordinator so ownership or ordering can be adjusted. Keep external actions and integration checks with the coordinator unless assigned explicitly.

Return the changed paths, behavior exercised, commands and outcomes, and any skipped checks or deviations. Flag the specific user journey for independent browser review when the result is visible through a browser.
