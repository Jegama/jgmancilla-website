# Projects

## Modular Survey Analysis System
**ID:** `proj_modular_survey`

- Weekly sentiment survey dashboard; reduced report generation from ~4h to <5m.
- Prototype open-ended classifier (precursor to Meta system) using NLP and clustering.
- Context-aware survey logic parsing and automated statistical summaries.
- Reported end-to-end analysis effort reduced ~70%, with estimated ~50% resource savings.
- Autonomous clustering for open-endeds: clusters responses, assigns category names, and drafts category descriptions (patent pending/in process).

## AI Knowledge Assistant (LangGraph, RAG, Evaluation Systems)
**ID:** `proj_ai_knowledge_assistant_4`

- TTFT p95 4.3s to under 2s; about 33% hallucination reduction (internal).
- Re-platformed to Next.js/TypeScript with LangGraph multi-agent 'Council of Three' ensemble.
- Built a custom Next.js analytics suite for 'LLM-as-a-judge' benchmarking, running automated regression tests on a 500+ item dataset to track Adherence, Tone, and Reasoning.
- Benchmarked GPT-5 Mini vs Grok 4.1 Fast; identified complex scenarios requiring nuanced alignment on sensitive topics as the decisive differentiator (4.79 vs 4.73).
- Tuned Gemini 2.5 Flash system prompts to improve baseline performance by ~12%, closing the gap with top performers.
- Engineered a parallelized entity classification pipeline (Tavily + 6x Gemini 2.5 Flash instances) to audit organizations against strict Zod compliance schemas.
- Achieved >90% alignment with human expert labels for entity auditing while reducing costs to fractions of a cent per run using small, fast models.
- Single RAG pipeline; nightly indexing of a 900-book library; edge streaming UX.
- Added observability/telemetry and review loops to monitor answer quality and prioritize fixes.

## Quant UX Research at Scale
**ID:** `proj_quant_ux_scale`

- Reduced open-ended analysis time from ~30h to <8h (~73% reduction) for a 500M+ MAU product.
- Doubled survey analysis throughput without adding headcount, enabling the team to handle higher-volume roadmap validation.
- 6-step GenAI pipeline: Embeddings, Council of Agents (Self-consistency), LLM-as-a-judge, Verifier-driven revisions, HITL, Few-shot curation.
- Longitudinal study tracking model performance pre/post-launch via log analysis.
- Standardized statistical validation (regressions/ANOVA/T-tests) adopted by the wider research team.
- Embedded SME acceptance tests and feedback loops to refine label taxonomies and prevent semantic drift.
- Triangulated survey outputs with behavioral logs (e.g., editor log data) to surface actionable discrepancies.

## Design Research: Driver Stress Elicitation
**ID:** `proj_design_research_stress`

- Real-world driver stress elicitation with repeatable, safe protocol and instrumentation.
- 90% stress replication rate; 89% alignment with observed road events; open API for detection algorithm.
- Mixed-methods instrumentation and cross-disciplinary collaboration ensured rigor and safety.
- Combined scripted stressors (e.g., battery warnings) and unscripted road events (e.g., pedestrians, construction) to increase ecological validity.

## User Research: Remote Benchmarking Framework
**ID:** `proj_user_research_remotes`

- Benchmarked hardware remotes across 70M+ devices by integrating behavioral logs with lab studies.
- Informed launch of a new remote (Fall '22) with validated interaction improvements.
- Expanded country/feature metrics and comparative dashboards for rapid evaluation.
- Scripted statistical analyses and repeatable workflows to reduce turnaround across a multi-year longitudinal program.
